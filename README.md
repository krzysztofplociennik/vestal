# Vestal

A desktop app that manages a single local repository of notes in .txt files. 

## What it does

- **Pushes** changes from a local repository to a GitHub repository
- **Pulls** a GitHub repository down to a local folder
- **Encrypts/decrypts** notes locally, so you don't store sensitive content in plain text — even in a private repo.

The goal is a single source of truth for your notes, kept consistent across different machines and operating systems, 
using Git as the sync mechanism.

## Status

🚧 Early development — not yet functional.

## Tech stack

- Java + JavaFX (desktop UI)
- JGit (Git operations, no external `git` binary required)
